    Step 2 — Brace Type & Orientation

    B
    45° to 59° from vertical

    Flatter braces carry more axial load for the same seismic force. Component listed ratings are adjusted per Table 18.5.2.3 — 30–44°: ÷2.000, 45–59°: ÷1.414, 60–90°: ÷1.155 — so steeper braces keep more of their rated capacity.

    Brace Elevation (Cp height reduction)

    A brace low in the building gets a reduced Cp (18.5.9.3.3/.3.4): below 50% of the average roof height ×0.75, 50–75% ×0.875. Applies to the SDS-formula editions (2025 / 2022 post-TIA). Set per brace — each brace sits at its own elevation.

    Layers to import

    Each color becomes its own CAD layer.

    Stroke weights from the PDF are bucketed into thick / medium / thin and split onto –W050 / –W025 / –W010 layers; stipple & hatch dots land on a –HATCH layer so you can restyle or delete them in one pick.     Hazen-Williams calculator

    Pipe Friction Loss

    Pipe & flow

    Pick a pipe and enter a flow — results update live.

    C = 100black steel — dry pipe / preaction, unlined cast iron
    C = 120black steel — wet pipe / deluge, galvanized steel
    C = 140cement-lined ductile / cast iron
    C = 150copper tube, CPVC, PEX, HDPE

    Default C factors per NFPA 13 Table 23.4.4.7.1 — the values above load automatically with each pipe type, and you can override them for aged or specialty pipe.

    Results

    Friction Loss -
    Total Friction Loss - Enter a length to see the total.

    Shown work

    p = 4.52 × Q^1.85 / (C^1.85 × d^4.87)

    p = friction loss (psi/ft), Q = flow (gpm), C = Hazen-Williams roughness coefficient, d = actual internal diameter (in) — NFPA 13 form. Straight-pipe friction only; fittings and elevation are not included.
